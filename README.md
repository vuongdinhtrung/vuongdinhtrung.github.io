# vuongdinhtrung.github.io

Personal academic website of **Vuong Dinh Trung** (VinUniversity), served by GitHub Pages at https://vuongdinhtrung.github.io

Plain HTML + CSS, no build step.

| File | Page |
|---|---|
| `index.html` | About / CV |
| `team.html` | Close co-authors and mentored students |
| `collaborators.html` | Corresponding-author collaborators |
| `publications.html` | Articles, under review, book chapter, patents, presentations |
| `outreach.html` | News, editorial work, service, curriculum, memberships |
| `contact.html` | Contact and map |
| `style.css` | Shared styles |
| `banner.svg` | Header image |

**Editing:** open a file on GitHub, click the pencil icon, edit, then *Commit changes*. The site updates in 1–2 minutes.

**Profile photo:** replace `profile.jpg` (square image) in the repository root. If the file is missing, a "VDT" monogram is shown.
