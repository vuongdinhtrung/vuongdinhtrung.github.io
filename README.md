# vuongdinhtrung.github.io

Personal academic website of **Vuong Dinh Trung** (VinUniversity), served by GitHub Pages at https://vuongdinhtrung.github.io

## How it is built

The HTML pages are generated by `_src/build.py` (all page content lives there).

**Automatic updates.** The workflow `.github/workflows/update.yml` runs 3 times a day:

1. `_src/update.py` reads ORCID (journal articles, peer-review count), Crossref (details of new articles) and the Google Scholar profile (citations, h-index, i10-index) into `_src/data.json`.
2. `_src/build.py .` rebuilds the pages. Articles on ORCID that are not yet curated in `build.py` are added to the publication list automatically.
3. Changes are committed and the site redeploys.

To update immediately: **Actions → Auto-update publications and metrics → Run workflow**.

If Google Scholar blocks a request, the last known numbers are kept. To add journal metrics (IF, Scopus top %) or edit any text, edit `_src/build.py`.

**Profile photo:** replace `profile.jpg` (square image).
